# Nova v0.8.0 — Skills Engine

Skills Engine convierte procedimientos repetibles en playbooks locales y declarativos.

## Objetivo

Una Skill describe **qué hacer**, con qué parámetros, qué herramientas son apropiadas y cómo verificar el resultado. No es código ejecutable y no puede concederse permisos a sí misma.

Flujo:

```text
petición del usuario
      ↓
matching local de Skills
      ↓
Skill relevante
      ↓
compilar parámetros
      ↓
playbook declarativo
      ↓
Agent + LocalTools
      ↓
seguridad/confirmaciones normales
      ↓
verificación
      ↓
historial local de ejecución
```

## Datos persistentes

`data/skills.db` contiene:

- definición de Skills;
- revisiones anteriores cuando una Skill se actualiza;
- triggers;
- parámetros declarativos;
- pasos y verificaciones;
- alcance global o por workspace;
- contadores de ejecuciones verificadas/fallidas;
- historial técnico de ejecuciones.

Por defecto **no se persisten resúmenes completos de ejecución**.

## Seguridad

- Las Skills nunca ejecutan Python, PowerShell u otro código por sí mismas.
- `permissions` describe capacidades esperadas; jamás reemplaza la política de seguridad de Nova.
- Una Skill no puede desactivar confirmaciones.
- Definiciones que parecen contener tokens, claves privadas, API keys o secretos conocidos se rechazan.
- Parámetros con nombres sensibles (`password`, `token`, `secret`, `cookie`, `api_key`, etc.) se redactan en SQLite y **no se interpolan al playbook**.
- Los pasos persistidos en `skill_runs` son los templates originales, no versiones con valores ya sustituidos.
- Contenido externo futuro (web, visión o ChatGPT Assisted Escalation) no se convierte automáticamente en una Skill confiable.

## Confianza

Una Skill puede estar en:

- `draft`: generada por Nova o todavía sin suficiente historial;
- `user`: creada a petición explícita del usuario;
- `verified`: una Skill `draft` con al menos dos ejecuciones distintas marcadas como verificadas correctamente.

La confianza no modifica permisos; solo indica historial.

## Matching

Nova usa matching léxico local sobre:

- nombre;
- slug;
- frases trigger;
- descripción.

Por defecto `auto_execute_matches=false`: encontrar una Skill relevante no basta para ejecutarla automáticamente.

## Comandos naturales

Ejemplos:

```text
Nova, ¿qué habilidades tienes?
Nova, estado de habilidades.
Nova, usa la habilidad Reiniciar servidor server=Alpha.
Nova, guarda este procedimiento como una habilidad llamada Reparar servidor.
```

## Herramientas

- `skill_status`
- `skill_list`
- `skill_search`
- `skill_info`
- `skill_save`
- `skill_run`
- `skill_finish`
- `skill_set_enabled`
- `skill_runs`

## UI

La interfaz añade **🧩 Skills**, con una vista local de las Skills disponibles, su versión, alcance, confianza, estado y pasos. Crear/editar Skills se hace mediante lenguaje natural para no duplicar un editor complejo en esta primera versión.

## Base para las siguientes versiones

v0.8.0 prepara el terreno para:

- Confidence Engine;
- ChatGPT Assisted Escalation sin API;
- aprendizaje de procedimientos que funcionaron;
- conversión controlada de soluciones externas en Skills `draft`;
- selección semántica futura de Skills.
