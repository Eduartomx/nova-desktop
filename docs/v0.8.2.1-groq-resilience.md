# Nova v0.8.2.1 — Groq Resilience

Hotfix de Expert Escalation basado en las pruebas reales del proyecto.

## Cambios

- Groq pasa a ser el proveedor gratuito predeterminado.
- Modelo Groq predeterminado: `openai/gpt-oss-120b`.
- Cerebras queda como fallback secundario.
- El antiguo default `cerebras -> groq` se migra a `groq -> cerebras`.
- El antiguo modelo Groq `qwen/qwen3.6-27b` se migra a `openai/gpt-oss-120b` únicamente cuando sigue siendo el default conocido; modelos personalizados del usuario se respetan.
- Se añade circuit breaker persistente por proveedor en `data/expert_escalation.db`.

## Circuit breaker

Un proveedor se omite temporalmente después de errores HTTP que normalmente no se resolverán reintentando inmediatamente:

- `401/403`: 6 horas;
- `402`: 12 horas;
- `429`: 90 segundos;
- `5xx`: 120 segundos.

El estado se conserva entre reinicios para que Nova no vuelva a golpear un proveedor que acaba de fallar por billing/autorización.

Cuando el circuito está abierto, `ask_free()` continúa con el siguiente proveedor disponible.

La tabla `expert_provider_health` solo contiene:

- proveedor;
- instante de reapertura;
- motivo técnico;
- código HTTP;
- instante de actualización.

No guarda prompts, respuestas ni API keys.

## Groq

La API key se obtiene desde la variable de entorno `GROQ_API_KEY`. Nunca debe escribirse en `config.json` ni subirse al repositorio.

El endpoint configurado sigue siendo:

`https://api.groq.com/openai/v1/chat/completions`

Modelo:

`openai/gpt-oss-120b`

## ChatGPT Assisted

No cambia. ChatGPT sigue siendo la escalación final/manual: Nova prepara y copia la consulta, abre ChatGPT y el usuario envía el mensaje y copia la respuesta de vuelta.
