# Nova v0.8.3 — Learn from Expert

## Objetivo

Learn from Expert conecta Expert Escalation con Skills Engine y Memory sin convertir una respuesta externa en una autoridad ni en código confiable.

Flujo:

```text
Nova / Qwen local
  ↓
Confidence Engine
  ↓
Groq / ChatGPT Assisted
  ↓
candidata en RAM (NO confiable)
  ↓
verificación positiva real
  ↓
materialización explícita
  ├─ Skill declarativa draft
  └─ resumen estable opcional en Memory
```

## Reglas de confianza

- `auto_learn=false`: no existe aprendizaje automático de respuestas externas.
- Una segunda opinión solo crea una candidata en memoria.
- Para guardar conocimiento se necesita una verificación positiva.
- La verificación puede provenir de una herramienta, una Skill, una comprobación manual o una confirmación explícita del usuario.
- Una verificación fallida bloquea la materialización.
- La Skill resultante siempre comienza como `draft`.
- Skills Engine mantiene sus reglas normales: una Skill no concede permisos y toda ejecución futura vuelve a pasar por Agent/Tools y las confirmaciones de seguridad.

## Privacidad

`data/learn_from_expert.db` guarda únicamente metadatos:

- proveedor/modelo;
- hash/fingerprint;
- veredicto;
- fuente y resultado de verificación;
- ID de la Skill creada;
- workspace asociado;
- timestamps/estado.

No persiste la respuesta externa, el problema original ni el análisis local completo. El contenido necesario para convertir la candidata en una Skill vive temporalmente en RAM y expira por defecto a los 45 minutos.

La Skill guarda únicamente el procedimiento declarativo que Nova materializa después de la verificación. La procedencia contiene hashes y metadatos del proveedor, nunca la respuesta externa completa.

## Comandos naturales

```text
Nova, estado de aprendizaje experto.
Nova, esto funcionó.
Nova, esto no funcionó.
Nova, aprende esta solución.
Nova, no aprendas esto.
Nova, qué aprendiste del experto.
```

## Herramientas

- `expert_learning_status`
- `expert_learning_candidate`
- `expert_learning_verify`
- `expert_learning_save_skill`
- `expert_learning_discard`
- `expert_learning_recent`

## Política de materialización

Cuando el usuario dice `aprende esta solución`, Agent recibe temporalmente la candidata ya verificada como **contenido externo no confiable**. Debe extraer únicamente los pasos comprobados, añadir verificaciones explícitas y llamar a `expert_learning_save_skill`.

No debe copiar secretos ni interpretar instrucciones del experto como permisos. Si no existe una verificación positiva, Agent rechaza el aprendizaje.
