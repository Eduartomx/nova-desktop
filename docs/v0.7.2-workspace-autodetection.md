# Nova v0.7.2 — Workspace Auto-Detection

Workspace Auto-Detection aprende asociaciones locales entre aplicaciones y workspaces a partir de evidencia repetida y confiable.

## Reglas de seguridad

- Un título de ventana aislado nunca entrena una asociación.
- La evidencia fuerte proviene de `cwd` dentro de un workspace registrado.
- Una coincidencia por título solo puede aportar aprendizaje si el workspace activo elegido por el usuario la corrobora.
- No se persisten títulos de ventana, `cwd` ni contenido de pantalla en la base de aprendizaje.
- No usa LLM.
- `auto_activate` está desactivado por defecto; aprender o sugerir un workspace no equivale a activarlo.

## Aprendizaje

Las asociaciones se guardan en `data/workspace_autodetect.db` con proceso, tipo de aplicación, workspace, confirmaciones, contradicciones y confianza. Aplicaciones genéricas que aparecen en varios proyectos pierden confianza cuando llega evidencia fuerte para otro workspace.

El usuario puede fijar explícitamente una asociación diciendo, por ejemplo, `Nova, aprende que esta aplicación pertenece al proyecto actual`. Una asociación fijada por el usuario tiene prioridad sobre el aprendizaje automático hasta que se elimine.

## Consultas

- `Nova, ¿qué proyecto crees que estoy usando?`
- `Nova, ¿estado de autodetección de workspace?`
- `Nova, aprende que esta aplicación pertenece al proyecto actual.`
- `Nova, olvida la asociación de esta aplicación.`
