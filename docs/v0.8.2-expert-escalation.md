# Nova v0.8.2 — Expert Escalation

## Objetivo

Dar a Nova una segunda opinión externa cuando Confidence Engine detecta poco respaldo, sin convertir un proveedor externo en autoridad absoluta ni depender de la API de OpenAI de pago.

## Flujo

```text
petición
  ↓
Nova local / herramientas / Skills
  ↓
Confidence Engine
  ↓
¿es candidata a escalación?
  ├─ no → respuesta normal
  └─ sí
      ↓
      riesgo normal + API gratuita configurada
      ├─ sí → Cerebras → fallback Groq
      └─ no → conservar candidata local
                    ↓
           ChatGPT Assisted opcional
```

## API gratuita

### Cerebras — proveedor principal

Default: `gpt-oss-120b` mediante Chat Completions compatible con OpenAI.

La clave se obtiene del entorno `CEREBRAS_API_KEY`. El código no posee ningún valor secreto predeterminado y no escribe la clave en SQLite/config.

### Groq — fallback

Default: `qwen/qwen3.6-27b`, clave `GROQ_API_KEY`.

Se utiliza cuando Cerebras no está configurado/disponible y Groq sí lo está. También puede solicitarse explícitamente para obtener diversidad de modelo.

Los proveedores, modelos y tiers gratuitos son externos y pueden cambiar. El fallback evita convertir uno solo en dependencia absoluta.

## ChatGPT Assisted

Esta ruta está diseñada para aprovechar una sesión de ChatGPT controlada por el usuario sin tratar la interfaz web como API.

Nova puede:

1. reconstruir la candidata reciente en memoria;
2. minimizar y sanitizar el paquete;
3. copiar la consulta al portapapeles;
4. abrir `chatgpt.com` mediante el navegador predeterminado.

Nova **no**:

- pulsa Enviar;
- hace scraping de la respuesta;
- espera/captura silenciosamente la conversación;
- monitoriza continuamente el portapapeles.

El usuario envía la consulta y copia la respuesta. Después puede decir `Nova, importa la respuesta de ChatGPT`. La lectura del portapapeles ocurre únicamente en esa acción explícita.

## Paquete de evidencia

El paquete `NOVA_EXPERT_REQUEST` contiene únicamente:

- problema sanitizado y acotado;
- análisis local sanitizado y acotado;
- tipo/riesgo;
- índice heurístico de Confidence Engine;
- conteos de evidencia, verificaciones, fallos y contradicciones;
- una pregunta estructurada para la segunda opinión.

No se adjuntan bases de datos, historial de chat completo, archivos completos ni secretos de forma intencional.

## Tratamiento de respuestas externas

Cerebras, Groq y ChatGPT son **fuentes externas no confiables**. Su texto:

- no concede permisos;
- no cambia la política de seguridad;
- no puede ordenar instalaciones, eliminaciones o envíos por sí mismo;
- debe verificarse con evidencia local antes de ejecutar cambios.

Si Nova y el experto discrepan, la conducta correcta es encontrar una comprobación local que resuelva la discrepancia.

## Política de autoescalación

`auto_free_second_opinion=true` por defecto, pero únicamente para riesgo `normal`.

`high` y `critical` nunca salen automáticamente del equipo. La consulta externa requiere una orden explícita del usuario.

## Persistencia

`data/expert_escalation.db` conserva solo metadatos de ejecución:

- método;
- proveedor/modelo;
- trigger;
- tipo/riesgo;
- índice de Confidence Engine;
- estado/veredicto;
- tamaños de payload/respuesta;
- código de error técnico;
- SHA-256 del paquete.

No existen columnas para guardar prompt o respuesta.

La candidata reciente y una respuesta ChatGPT importada permanecen solo en memoria de proceso.

## Configuración en Windows

Cerebras:

```powershell
[Environment]::SetEnvironmentVariable("CEREBRAS_API_KEY", "TU_CLAVE", "User")
```

Groq opcional:

```powershell
[Environment]::SetEnvironmentVariable("GROQ_API_KEY", "TU_CLAVE", "User")
```

Reinicia Nova después. No escribas claves dentro de `config.json`.

## OpenAI API

Desde v0.8.2 la API de OpenAI queda deshabilitada por defecto y se migra el antiguo default si nunca hubo un opt-in explícito. Expert Escalation no contiene endpoint ni variable `OPENAI_API_KEY`.

ChatGPT Assisted es un flujo separado: el usuario controla la sesión web y realiza manualmente Enviar/Copiar.
