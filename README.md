# Nova Desktop

Nova es un asistente virtual local para Windows orientado a comprender el estado del PC,
automatizar tareas, navegar por Internet, usar herramientas locales y evolucionar hacia
un agente de escritorio completo.

## Estado

Versión base del canal de actualizaciones: **v0.5.7**

## Actualizaciones

Las versiones estables se publican mediante **GitHub Releases**. Nova consulta la release
estable más reciente y descarga el asset `Nova_Parche_*.zip`.

## Privacidad

Este repositorio no debe contener datos personales de la instalación local. La memoria,
bases SQLite, perfiles del navegador, capturas, claves API y configuración privada permanecen
fuera del repositorio.
